## 🔧 最后一个关键修复

**问题**: FieldComponentMapper Bean 无法找到

**原因**: `@MapperScan` 只扫描了 `com.contract.adapter.persistence.mapper`，但 FieldComponentMapper 在 `com.contract.infrastructure.persistence.mapper`

**修复**:
```java
@MapperScan({"com.contract.adapter.persistence.mapper", 
             "com.contract.infrastructure.persistence.mapper"})
```
