# 🎨 可视化配置系统 - 快速启动指南

## 📋 系统架构（已完成）

### ✅ 三个独立的界面系统

```
1. 模板配置界面（可视化设计器）
   ├─ 左侧：实时预览区（40%）
```

## 🎯 功能测试流程

### 测试1：配置模板

**步骤**：

1. 打开模板设计器
   ```
   http://localhost:8888/config/template-designer.html
   ```

2. 从右侧组件库拖拽组件到左侧预览区
   ```
   - 拖拽"卡片组件"创建布局
   - 拖拽"输入框组件"添加字段
   - 拖拽"下拉框组件"添加选项
   ```

3. 点击预览区的组件，右侧显示配置表单
   ```
   配置属性：
   - 组件名称：合同名称
   - 字段路径：basic.contractName
   - 数据类型：STRING
   - 是否必填：勾选
   ```

4. 配置规则
   ```
   可见性规则：
   - 条件：basic.contractType == 'PURCHASE'
   - 效果：当合同类型为采购时显示

   必填规则：
   - 条件：basic.totalAmount > 100000
   - 效果：金额超过10万时必填审批意见
   ```

5. 点击"保存配置"按钮
   ```
   配置保存到数据库：
   - 布局节点树
   - 字段定义
   - 组件配置
   - 规则配置
   ```

### 测试2：配置数据源

**步骤**：

1. 打开数据源配置界面
   ```
   http://localhost:8888/config/data-source.html
   ```

2. 创建静态数据源（币种）
   ```
   类型：静态数据
   名称：币种列表
   数据：
   [
     {"value": "CNY", "label": "人民币"},
     {"value": "USD", "label": "美元"}
   ]
   ```

3. 创建HTTP数据源（供应商查询）
   ```
   类型：HTTP接口
   名称：供应商查询
   URL：http://api.example.com/suppliers
   方法：GET
   参数映射：keyword → q
   ```

4. 测试数据源连接
   ```
   点击"测试"按钮验证配置是否正确
   ```

### 测试3：查看动态渲染效果

**步骤**：

1. 打开动态展示界面
   ```
   http://localhost:8888/display/dynamic-display.html
   ```

2. 选择模板
   ```
   从下拉框选择刚才配置的模板
   ```

3. 观察动态渲染
   ```
   - 界面根据配置自动渲染
   - 规则自动执行（显隐、必填）
   - 数据源自动加载（下拉选项）
   ```

4. 测试规则效果
   ```
   - 选择合同类型：采购 → 观察组件显隐变化
   - 输入金额：15万 → 观察必填规则生效
   ```
