## 🎯 推荐方案：使用 IntelliJ IDEA（最快最简单）

### 步骤（5步，30秒完成）

1. **打开 IntelliJ IDEA**
   - 如果已打开，跳过此步
   - 否则，从应用菜单启动 IDEA

2. **打开项目**
   ```
   File → Open → 选择 /home/wula/IdeaProjects/dymic
   ```

3. **等待项目加载**
   - IDEA 会自动识别这是 Spring Boot 项目
   - 等待右下角进度条完成（可能需要1-2分钟）
   - 首次打开需要下载依赖

4. **运行应用**
   ```
   找到文件：src/main/java/com/contract/ContractTemplateApplication.java
   点击代码行号旁边的绿色三角形 ▶️
   或者：右键 → Run 'ContractTemplateApplication'
   ```

5. **等待启动完成**
   - 查看底部 Run 标签页的日志
   - 等待显示："Started ContractTemplateApplication in X seconds"
   - 通常需要 10-30 秒

## 🐛 如果启动失败

### 问题1：端口8080被占用

**解决方案**：
修改 `src/main/resources/application.yml`：
```yaml
server:
  port: 9090  # 改为其他端口
```

然后访问：http://localhost:9090/index.html

### 问题2：依赖下载失败

**解决方案**：
1. IDEA会自动尝试重新下载
2. 检查网络连接
3. 或者手动安装Maven：
   ```bash
   sudo apt-get install -y maven
   ```

### 问题3：找不到主类

**解决方案**：
1. 号新建项目：File → Invalidate Caches → Invalidate and Restart
2. 等待重新加载
3. 再次运行
