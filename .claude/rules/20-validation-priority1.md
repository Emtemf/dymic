# 优先级1验证步骤

## 核心原则

**最小闭环验证**：模板配置 + 合同录入 + E2E验证工具，构成V1.0的核心功能闭环。

---

## 验证范围

### 功能模块
1. **模板管理**
   - 创建模板（编码、名称、描述）
   - 停用/启用模板
   - 当前版本管理

2. **版本管理**
   - 创建草稿版本
   - 发布版本（只有草稿能发布）
   - 版本状态管理（DRAFT/PUBLISHED）

3. **配置管理**
   - 布局节点配置（树形结构）
   - 字段定义配置（路径、类型）
   - 组件绑定配置（组件类型、属性）

4. **合同录入**
   - 新增合同（根据配置动态渲染）
   - 编辑合同（从快照回显）
   - 保存合同（生成快照、建立索引）

---

## 验证步骤

### 步骤1：Repository层验证（H2）

#### 模板Repository验证
```
1. 创建模板测试
   - 验证保存操作返回正确ID
   - 验证字段正确持久化
   - 验证审计字段自动填充

2. 查询模板测试
   - 验证按ID查询返回正确数据
   - 验证按编码查询返回正确数据
   - 验证条件查询返回符合条件的数据
   - 验证分页查询返回正确分页信息

3. 更新模板测试
   - 验证更新操作正确修改数据
   - 验证只更新指定字段

4. 状态变更测试
   - 验证启用/停用操作正确
   - 验证状态校验规则生效
```

#### 版本Repository验证
```
1. 创建版本测试
   - 验证版本关联正确模板
   - 验证版本号正确生成
   - 验证初始状态为DRAFT

2. 发布版本测试
   - 验证状态变更正确
   - 验证发布时间记录
   - 验证发布人记录

3. 查询版本测试
   - 验证按模板ID查询版本列表
   - 验证按状态查询版本列表
```

---

### 步骤2：Service层验证（Mock）

#### 模板Service验证
```
1. 创建模板业务测试
   - 验证编码唯一性校验
   - 验证必填字段校验
   - 验证DTO转换正确
   - 验证调用Repository正确

2. 更新模板业务测试
   - 验证模板存在性校验
   - 验证状态变更规则
   - 验证版本号处理

3. 删除模板业务测试
   - 验证关联版本处理
   - 验证逻辑删除实现
```

#### 版本Service验证
```
1. 创建版本业务测试
   - 验证模板状态校验
   - 验证版本号生成规则
   - 验证配置JSON格式

2. 发布版本业务测试
   - 验证草稿状态校验
   - 验证配置完整性校验
   - 验证发布时间记录

3. 版本查询业务测试
   - 验证当前版本获取逻辑
   - 验证历史版本查询
```

#### 配置Service验证
```
1. 配置保存业务测试
   - 验证配置JSON格式校验
   - 验证配置完整性校验
   - 验证配置引用校验

2. 配置查询业务测试
   - 验证按版本ID查询配置
   - 验证配置解析正确
```

---

### 步骤3：Controller层验证（MockMvc）

#### 模板Controller验证
```
1. POST /api/templates
   - 验证创建成功返回201
   - 验证参数校验生效
   - 验证编码重复返回400
   - 验证响应格式统一

2. GET /api/templates/{id}
   - 验证查询成功返回200
   - 验证不存在返回404
   - 验证响应数据格式

3. PUT /api/templates/{id}
   - 验证更新成功返回200
   - 验证参数校验生效
   - 验证不存在返回404

4. DELETE /api/templates/{id}
   - 验证删除成功返回200
   - 验证不存在返回404

5. GET /api/templates
   - 验证分页查询返回正确格式
   - 验证分页参数生效
```

#### 版本Controller验证
```
1. POST /api/templates/{templateId}/versions
   - 验证创建成功返回201
   - 验证模板不存在返回404

2. PUT /api/templates/{templateId}/versions/{versionId}/publish
   - 验证发布成功返回200
   - 验证草稿状态校验返回400

3. GET /api/templates/{templateId}/versions
   - 验证版本列表查询成功
```

### 步骤4：前端界面验证（chrome-devtools）

#### 模板配置界面验证
```
1. 页面加载
   - 验证配置界面正确渲染
   - 验证预览区域正确显示
   - 验证工具栏按钮可用

2. 创建模板
   - 验证表单填写
   - 验证参数校验提示
   - 验证保存成功提示
   - 验证列表刷新

3. 编辑模板
   - 验证数据加载
   - 验证修改保存
   - 验证版本管理

4. 配置操作
   - 验证布局节点添加
   - 验证字段定义配置
   - 验证组件绑定配置
```

#### 合同录入界面验证
```
1. 选择模板
   - 验证模板选择器可用
   - 验证模板列表显示

2. 动态渲染
   - 验证表单根据配置渲染
   - 验证字段类型正确
   - 验证组件绑定正确

3. 数据录入
   - 验证字段填写
   - 验证数据绑定
   - 验证保存成功

4. 合同回显
   - 验证编辑界面数据加载
   - 验证数据回显正确
```

---

### 步骤5：E2E闭环验证

#### 完整闭环流程
```
1. 创建模板
   - 创建模板（编码: TEST001, 名称: 测试模板）
   - 验证模板创建成功

2. 创建版本
   - 创建草稿版本
   - 配置布局和字段
   - 发布版本
   - 验证版本发布成功

3. 新增合同
   - 选择模板
   - 根据配置填写表单
   - 保存合同
   - 验证保存成功

4. 编辑合同
   - 打开已保存合同
   - 验证数据回显正确
   - 修改数据
   - 保存修改
   - 验证修改成功
```
