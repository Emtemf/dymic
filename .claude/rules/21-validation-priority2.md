# 优先级2验证步骤

## 核心原则

**增强功能验证**：查询配置 + 数据源配置，扩展模板的自动化填充能力。

---

## 验证范围

### 功能模块
1. **查询配置**
   - 查询配置创建
   - 查询参数配置
   - 回填规则配置
   - 查询执行验证

2. **数据源配置**
   - 静态数据源（手动JSON）
   - 字典数据源（系统字典）
   - HTTP数据源（外部API）
   - 平台数据源（内部服务）
   - 内部数据源（业务查询）

---

## 验证步骤

### 步骤1：Repository层验证（H2）

#### 数据源Repository验证
```
1. 创建数据源测试
   - 验证数据源保存正确
   - 验证数据源类型字段
   - 验证配置JSON保存

2. 查询数据源测试
   - 验证按ID查询数据源
   - 验证按类型查询数据源
   - 验证按模板ID查询数据源

3. 更新数据源测试
   - 验证配置更新
   - 验证状态变更
```

#### 查询配置Repository验证
```
1. 创建查询配置测试
   - 验证查询配置保存
   - 验证关联数据源正确
   - 验证参数配置保存
   - 验证回填规则保存

2. 查询查询配置测试
   - 验证按模板ID查询
   - 验证按版本ID查询
   - 验证按字段路径查询
```

---

### 步骤2：Service层验证（Mock）

#### 数据源Service验证
```
1. 创建数据源业务测试
   - 验证数据源类型校验
   - 验证配置格式校验
   - 验证数据源唯一性

2. HTTP数据源测试
   - 验证URL格式校验
   - 验证请求方法校验
   - 验证请求头配置
   - 验证响应格式解析

3. 平台数据源测试
   - 验证服务标识校验
   - 验证接口路径校验
   - 验证参数映射

4. 内部数据源测试
   - 验证业务对象校验
   - 验证查询方法校验
   - 验证参数绑定
```

#### 查询配置Service验证
```
1. 创建查询配置业务测试
   - 验证数据源关联校验
   - 验证参数配置校验
   - 验证回填规则校验

2. 执行查询业务测试
   - 验证参数组装正确
   - 验证数据源调用正确
   - 验证结果转换正确
   - 验证回填规则执行正确

3. 回填业务测试
   - 验证单字段回填
   - 验证多字段回填
   - 验证映射规则执行
```

#### Gateway验证（外部数据源）
```
1. HTTP Gateway测试
   - 验证HTTP请求发送
   - 验证请求参数传递
   - 验证响应解析
   - 验证错误处理

2. 平台 Gateway测试
   - 验证内部服务调用
   - 验证参数转换
   - 验证结果转换
```

---

### 步骤3：Controller层验证（MockMvc）

#### 数据源Controller验证
```
1. POST /api/datasources
   - 验证创建成功返回201
   - 验证配置校验生效
   - 验证类型校验生效

2. GET /api/datasources/{id}
   - 验证查询成功返回200
   - 验证不存在返回404

3. PUT /api/datasources/{id}
   - 验证更新成功返回200
   - 验证配置更新生效

4. GET /api/datasources
   - 验证按类型筛选
   - 验证分页查询
```

#### 查询配置Controller验证
```
1. POST /api/templates/{templateId}/queries
   - 验证创建成功返回201
   - 验证数据源关联校验

2. PUT /api/templates/{templateId}/queries/{queryId}
   - 验证更新成功返回200

3. POST /api/queries/{queryId}/execute
   - 验证查询执行成功返回200
   - 验证返回数据格式
   - 验证查询参数传递
```

---

### 步骤4：前端界面验证（chrome-devtools）

#### 数据源配置界面验证
```
1. 静态数据源
   - 验证JSON编辑器可用
   - 验证JSON格式校验
   - 验证数据保存

2. 字典数据源
   - 验证字典选择器可用
   - 验证字典数据加载
   - 验证字典类型选择

3. HTTP数据源
   - 验证URL配置输入
   - 验证请求方法选择
   - 验证请求头配置
   - 验证参数映射配置
   - 验证响应解析配置

4. 平台数据源
   - 验证服务选择器可用
   - 验证接口路径配置
   - 验证参数映射配置

5. 内部数据源
   - 验证业务对象选择
   - 验证查询方法选择
   - 验证参数绑定配置
```

#### 查询配置界面验证
```
1. 查询配置创建
   - 验证数据源选择器可用
   - 验证参数配置界面
   - 验证回填规则配置界面

2. 查询执行界面
   - 验证查询选择窗口打开
   - 验证查询条件填写
   - 验证查询执行按钮
   - 验证查询结果显示
   - 验证数据选择操作
```

---

### 步骤5：E2E闭环验证

#### 查询配置完整闭环
```
1. 创建数据源
   - 创建静态数据源（JSON格式）
   - 验证数据源保存成功

2. 配置查询
   - 在模板配置中添加查询配置
   - 配置参数映射
   - 配置回填规则
   - 验证配置保存成功

3. 合同录入使用查询
   - 新增合同
   - 打开查询选择窗口
   - 执行查询
   - 选择数据
   - 验证字段回填正确

4. 保存合同
   - 验证回填数据保存
   - 验证合同数据完整
```
