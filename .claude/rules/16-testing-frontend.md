# 前端界面验证规则

## 核心原则

**前端界面验证**：使用chrome-devtools进行E2E测试，验证用户交互和数据流。

---

## 测试策略

### 测试范围
- 页面渲染验证
- 表单交互验证
- 数据绑定验证
- 规则执行验证（显隐、必填、只读）
- API调用验证

### 测试工具
- Chrome DevTools MCP
- 截图验证
- 网络请求验证

---

## 测试场景

### 场景1：模板配置界面

#### 页面加载验证
```
1. 打开模板配置页面
2. 验证页面标题正确显示
3. 验证配置面板正确渲染
4. 验证预览区域正确显示
5. 验证工具栏按钮可用
```

#### 配置操作验证
```
1. 创建模板配置
   - 填写模板编码（必填）
   - 填写模板名称（必填）
   - 选择组件类型
   - 配置字段属性
   - 保存配置
   - 验证保存成功提示

2. 编辑模板配置
   - 加载已有配置
   - 修改配置内容
   - 保存修改
   - 验证修改成功

3. 删除模板配置
   - 确认删除操作
   - 验证删除成功
```

### 场景2：合同录入界面

#### 动态渲染验证
```
1. 选择模板
2. 验证表单动态渲染
   - 文本框渲染正确
   - 下拉框选项正确
   - 日期控件正确
   - 数字输入框正确

3. 验证规则执行
   - 显隐规则正确执行
   - 必填校验正确执行
   - 只读控制正确执行
```

#### 数据绑定验证
```
1. 填写表单数据
2. 验证数据绑定
   - 输入值正确保存
   - 格式化正确
   - 校验规则生效

3. 保存合同
   - 提交表单
   - 验证API调用
   - 验证保存成功
```

### 场景3：查询选择

#### 查询配置验证
```
1. 打开查询选择窗口
2. 验证查询条件正确显示
3. 执行查询
4. 验证查询结果
5. 选择数据
6. 验证字段回填
```

## Chrome DevTools使用

### 工具加载
需要使用 `mcp__chrome-devtools` 工具进行前端测试。

### 常用操作

#### 1. 页面导航
```
使用 navigate_page 打开目标页面
```

#### 2. 元素点击
```
使用 click 点击按钮或链接
```

#### 3. 表单填写
```
使用 fill 或 fill_form 填写表单字段
```

#### 4. 截图验证
```
使用 take_screenshot 截取页面截图
使用 take_snapshot 获取DOM快照
```

#### 5. 网络请求验证
```
使用 list_network_requests 查看网络请求
使用 get_network_request 获取请求详情
```

#### 6. 控制台验证
```
使用 list_console_messages 查看控制台消息
使用 get_console_message 获取消息详情
```

## 测试脚本示例

### 示例1：验证模板配置保存
```
1. 导航到模板配置页面
   - 使用 navigate_page 打开 /template/config

2. 填写配置信息
   - 使用 fill 填写模板编码
   - 使用 fill 填写模板名称
   - 使用 click 选择组件类型

3. 保存配置
   - 使用 click 点击保存按钮
   - 使用 take_screenshot 截图验证

4. 验证保存成功
   - 使用 list_console_messages 检查成功消息
   - 使用 get_network_request 验证API调用
```

### 示例2：验证动态渲染
```
1. 打开合同录入页面
   - 使用 navigate_page 打开 /contract/create

2. 选择模板
   - 使用 click 打开模板选择
   - 使用 click 选择模板

3. 验证渲染结果
   - 使用 take_snapshot 获取DOM结构
   - 验证字段数量正确
   - 验证字段类型正确

4. 验证规则执行
   - 使用 fill 填写触发字段
   - 使用 take_screenshot 验证显隐变化
   - 验证必填提示出现
```

### 示例3：验证查询选择
```
1. 触发查询选择
   - 使用 click 点击查询按钮

2. 执行查询
   - 使用 fill 填写查询条件
   - 使用 click 点击查询按钮

3. 选择数据
   - 使用 take_screenshot 验证查询结果
   - 使用 click 选择数据行

4. 验证字段回填
   - 使用 take_snapshot 获取表单数据
   - 验证目标字段已填充
```
