# 优先级3验证步骤

## 核心原则

**高级功能验证**：明细表配置 + 外部数据接入，实现复杂业务场景支持。

---

## 验证范围

### 功能模块
1. **明细表配置**
   - 明细表结构配置
   - 明细表增删改配置
   - 明细表列配置
   - 明细表规则配置

2. **规则配置**
   - 显隐规则配置
   - 必填规则配置
   - 只读规则配置
   - 规则执行验证

3. **外部数据接入**
   - 外部消息接收（幂等入库）
   - 数据映射转换（外部→统一JSON）
   - 数据对比（逐字段差异）
   - 对比结果应用（自动/手动确认）

---

## 验证步骤

#### 明细表配置Repository验证
```

2. 查询明细表配置测试

   - 验证按版本ID查询
   - 验证按路径查询
```

#### 规则配置Repository验证
```
1. 创建规则配置测试
   - 验证显隐规则保存
   - 验证必填规则保存
   - 验证只读规则保存

2. 查询规则配置测试
   - 验证按模板ID查询
   - 验证按版本ID查询
   - 验证按字段路径查询
```

#### 外部数据Repository验证
```
1. 外部消息接收测试
   - 验证消息幂等保存
   - 验证消息状态记录
   - 验证消息处理状态

2. 数据映射测试
   - 验证映射规则保存
   - 验证映射结果保存

3. 数据对比测试
   - 验证对比结果保存
   - 验证差异记录保存
```

### 步骤3：Controller层验证（MockMvc）

#### 明细表配置Controller验证
```
1. POST /api/templates/{templateId}/detail-tables
   - 验证创建成功返回201
   - 验证配置校验生效

2. PUT /api/templates/{templateId}/detail-tables/{detailTableId}
   - 验证更新成功返回200
   - 验证配置更新生效

3. GET /api/templates/{templateId}/detail-tables
   - 验证明细表列表查询
```

#### 规则配置Controller验证
```
1. POST /api/templates/{templateId}/rules
   - 验证创建成功返回201
   - 验证规则类型校验

2. PUT /api/templates/{templateId}/rules/{ruleId}
   - 韧证更新成功返回200

3. GET /api/templates/{templateId}/rules
   - 验证规则列表查询
```

#### 外部数据Controller验证
```
1. POST /api/external-messages
   - 验证消息接收成功返回200
   - 验证幂等处理返回

2. POST /api/external-messages/{messageId}/mapping
   - 验证映射执行成功返回200
   - 验证映射结果返回

3. POST /api/external-messages/{messageId}/compare
   - 验证对比执行成功返回200
   - 验证差异结果返回

4. POST /api/external-messages/{messageId}/apply
   - 验证应用成功返回200
   - 验证应用结果返回
```

### 步骤5：E2E闭环验证

#### 明细表完整闭环
```
1. 配置明细表
   - 在模板中添加明细表配置
   - 配置明细表列
   - 配置明细表规则
   - 验证配置保存

2. 使用明细表
   - 新增合同
   - 增加明细表行
   - 填写明细表数据
   - 验证数据绑定
   - 验证规则执行
   - 保存合同
   - 验证明细表数据保存

3. 编辑合同明细表
   - 打开已保存合同
   - 验证明细表数据回显
   - 编辑明细表行
   - 删除明细表行
   - 保存修改
```

#### 规则执行完整闭环
```
1. 配置规则
   - 配置显隐规则（条件：字段A=X时显示字段B）
   - 配置必填规则（条件：字段A=X时字段B必填）
   - 配置只读规则（条件：字段A=X时字段C只读）
   - 验证规则保存

2. 规则执行验证
   - 新增合同
   - 填写字段A
   - 验证显隐规则生效（字段B显示）
   - 验证必填规则生效（字段B必填校验）
   - 验证只读规则生效（字段C禁用）
   - 保存合同
```

#### 外部数据完整闭环
```
1. 接收外部消息
   - 接收外部消息
   - 验证消息幂等保存
   - 验证消息状态记录

2. 数据映射
   - 执行数据映射
   - 验证映射规则执行
   - 验证映射结果生成

3. 数据对比
   - 执行数据对比
   - 验证字段逐一对比
   - 验证差异结果显示

4. 结果应用
   - 选择应用方式（自动/手动）
   - 执行结果应用
   - 验证数据更新正确
```
