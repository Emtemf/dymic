优点

  • 紧凑，占用空间少
  • 步骤清晰（1→2→3）
  • 实时预览，所见即所得

缺点

  • 没有独立组件库，需要下拉选择
  • 不够直观，业务人员需要理解步骤
  • 预留查询功能：需要额外步骤

关键决策：如何预留表格查询功能？

用户需求："肯定要有表格的查询功能的"

查询功能类型：

🔍 字段查询
点击字段旁边的查询按钮 → 弹出查询窗口 → 选择数据 → 回填字段
📊 表格查询
明细表的查询按钮 → 弹出查询窗口 → 选择多条数据 → 批量添加行
产品 数量

预留方案： 在字段组件配置时，添加"是否需要查询功能"选项， 明细表组件自带"批量查询"按钮属性。

✅ 我的推荐：方案A（三栏式）

理由：业务人员更直观，点击组件库 → 添加到画布 → 配置属性， 符合"所见即所得"的直觉。预留查询功能时，可以在属性面板中添加"查询配置"选项。
