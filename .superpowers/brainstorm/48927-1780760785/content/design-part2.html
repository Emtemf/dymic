📝 交互流程详解

从上到下配置流程

1
点击左侧"卡片容器" → 添加到画布顶部
2
点击卡片 → 右侧显示属性面板 → 配置卡片名称
3
点击左侧"文本输入框" → 添加到卡片内部
4
点击字段 → 右侧显示属性面板 → 配置字段名称、是否必填、查询功能
5
点击左侧"保存按钮" → 添加到画布底部

实时保存API调用

① 添加卡片：
POST /api/templates/{id}/versions/{vid}/layout-nodes
→ 自动生成 nodeCode、nodePath
② 添加字段：
POST /api/templates/{id}/versions/{vid}/field-defs
→ 同时创建 field-def + field-component
→ 自动生成 fieldCode、fieldPath、dataType
③ 更新字段属性：
PUT /api/field-defs/{fieldId}
PUT /api/field-components/{componentId}
→ 500ms延迟保存（避免频繁请求）
④ 添加按钮：
POST /api/templates/{id}/versions/{vid}/action-configs
→ 自动生成 actionCode

💾 实时保存 + 内存预览优化

混合方案实现细节

实时保存机制
  • ✓ 每次操作立即调用API保存
  • ✓ 500ms延迟保存（debounce）
  • ✓ 乐观更新：先更新UI，API失败后回滚
  • ✓ 自动生成技术字段（nodeCode、fieldPath等）
  • ✓ 配置不丢失（刷新页面后可恢复）
内存预览优化
  • ✓ 内存中维护配置树副本
  • ✓ 操作后立即更新内存配置树
  • ✓ 基于内存配置树渲染预览（无延迟）
  • ✓ 同时调用API验证（确保入库正确）
  • ✓ API失败时回滚内存配置树
预览渲染时机：
每次操作成功后，调用 GET /api/templates/{id}/versions/{vid}/schema → 渲染右侧预览
或基于内存配置树直接渲染（更快，但需要与API数据同步验证）
