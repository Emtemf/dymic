📋 三个新界面定位

1

config.html — 配置主界面

用途：业务人员配置模板结构

功能：左侧配置表单 + 右侧实时预览 + 保存按钮

用户：业务配置人员

2

preview.html — 独立预览界面

用途：验证已保存的配置渲染效果

功能：读取配置树 → 动态渲染表单

用户：开发验证用

3

data-viewer.html — 数据验证界面

用途：验证配置是否正确入库

功能：查看数据库中的配置 JSON

用户：开发验证用

💡 关键理解

simple.html/complex.html 是最终用户看到的合同录入界面， 不是配置界面。你需要的是config.html 配置界面， 让业务人员可以配置模板，实时预览，并验证数据入库。
