合同模板动态渲染系统 Demo

本 Demo 用于验证合同模板动态渲染系统的核心功能，包括模板创建、版本管理、合同生成等功能。

快速开始

1. 创建模板

创建一个采购合同模板，定义模板的基本信息和 JSON Schema。

2. 创建版本

为模板创建版本（如 V1.0），定义该版本的表单结构和验证规则。

3. 发布版本

将版本发布为可用状态，供后续合同创建使用。

4. 测试界面

使用简单界面或复杂界面测试合同的创建和渲染功能。
